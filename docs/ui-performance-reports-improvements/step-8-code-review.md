Findings:
- [High — fixed] Content spilled over card borders when the fixed content above a table was taller than the space left (user report: the Translations "Add Field" row was cut by the editor card's bottom edge). Cause: every wrapper in the height chain had `min-height: 0`, so a card could shrink below its own fixed content. Corrective action: `.table-scroll-frame` gets `contain: size` (its intrinsic height is only its 240px minimum), `.fill-column`, `.org-structure-layout` and the inline wrappers (IAM tables, translation editor, report cards, report/KPI Summary pages, both hub roots) drop `min-height: 0`; the org tree sidebar gets `contain: size` at ≥1024px. A card now never shrinks below fixed content + 240px; when the window is too short the page scrolls. Browser check (`table-scroll-checks.mjs` with a spill detector: boxed elements whose content exceeds their height), 1600×900 light and 1366×768 dark, every System/Reports scenario: 0 spills, tables still scroll on their own, 0 JS exceptions; at 1366×768 the Organization views now fit without a page scroll.

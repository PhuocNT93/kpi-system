# Frontend User Guide - Lucide React Dependency

## Prerequisites
- Node.js >= 18
- npm

## Installation & Commands
Trong thư mục `frontend/`, chạy lệnh:
```bash
npm install
```

Kiểm tra typecheck:
```bash
npm run typecheck
```

Chạy dev server:
```bash
npm run dev
```

Build production:
```bash
npm run build
```

## Configured Values & Behavior
- Cung cấp gói biểu tượng icon `lucide-react` cho Sidebar, AppLayout và các component khác.

# Team Reviews Frontend User Guide

## Overview
The **Team Reviews** module enables Managers, HR Admins, and System Admins to review and score team members' performance evaluations for active and past evaluation cycles.

## Prerequisites
- User must be logged in with role `MANAGER`, `HR_ADMIN`, or `SYSTEM_ADMIN`.
- Evaluations must be generated by opening an Evaluation Cycle.

## Accessing Team Reviews
1. In the sidebar navigation under the **Performance** section, click on **Team Reviews**.
2. Navigate directly to `/admin/team-evaluations`.

## Features
- **Search & Filter**: Search evaluations by employee name, employee code, or cycle name. Filter by review status (`Ready for Review`, `In Progress`, `Approved`).
- **Review List**: Cards summarizing team members, their department/team roles, assigned cycle, and submission status.
- **Scoring & Review**: Click on any evaluation to open the scoring interface.
  - Review self-assessment ratings and comments provided by the employee.
  - Select manager ratings (Level 1-5) for each criterion.
  - Enter reviewer evidence or feedback comments.
  - Save progress via **Save Draft**.
  - Finalize and submit review via **Approve & Finalize**.
